# Language Translator

A simple, lightweight desktop language translator built with Python and standard Tkinter. Originally built and shipped for the Stardance Challenge and PIXL, this updated version focuses on clean, straightforward code and a native desktop interface.

## Overview
This application provides a fast, easy-to-use desktop interface for translating text across multiple regional and international languages. In this refined release, the project was updated from heavy third-party styling wrappers to standard Python `tkinter`, resulting in a cleaner codebase, improved responsiveness, and zero extra UI dependencies.

## Features
* **Multi-Language Support:** Translate text seamlessly between English, German, French, Spanish, Hindi, Malayalam, Tamil, Telugu, and Kannada.
* **Classic & Lightweight UI:** Built using Python's built-in `tkinter` and `ttk` modules for a fast, native operating-system look and feel.
* **Smart Input Handling:** Automatically clears the placeholder prompt when you click inside the input box so you can start typing right away.
* **Quick Controls & Status Feedback:** Includes a dedicated **Clear All** button to reset fields, an **About** dialog, and a live status bar to track translation progress and errors.

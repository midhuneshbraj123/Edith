# Edith
A clean, beginner-friendly desktop application built in Python for the Stardance Challenge. This app provides a simple graphical interface to translate text between popular languages instantly.

Features: 
Modern Interface: Designed using `customtkinter` for a sleek dark-mode look.
Supported Languages: Translate smoothly between Hindi, English, Spanish, French, German, and Dutch.
Easy Controls: Includes straightforward text boxes, language dropdowns, and buttons for translating and clearing text.

Prerequisites
Before running the app, make sure you have Python installed on your computer, along with the required libraries. Open your terminal or command prompt and run:

pip install customtkinter deep-translator

How to Run the Project
1. Open your project folder in VS Code.
2. Open your terminal and ensure your script is saved as `app.py`.
3. Run the application by typing:

python app.py

Project Structure
`app.py`: The main Python file containing the user interface setup and Google translation logic.
`README.md`: Project documentation and guide.
